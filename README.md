# Control Home

A modern student productivity dashboard built to bring focus, discipline, and organization into one place.

Control Home combines essential productivity tools like task management, study tracking, Pomodoro sessions, sticky notes, and visual focus systems into a single clean dashboard experience designed especially for students.

## Features

- Poker-style productivity cards
- Pomodoro focus timer
- Sticky notes section
- Daily task management
- Study session tracking
- Minimal and distraction-free UI
- Dashboard-based workflow
- Fast and responsive experience
- Built for students and self-improvement enthusiasts

## Vision

Control Home is not just another productivity app.

It is designed as a personal command center for students who want clarity, structure, consistency, and momentum while working toward ambitious goals.
